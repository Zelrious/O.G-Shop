# Flyway migrations

Đặt migration đã được phê duyệt tại đây theo dạng:

```text
V1__initial_schema.sql
V2__add_feature_name.sql
```

Không sửa migration đã được chia sẻ hoặc chạy ở môi trường khác. Tạo migration mới để thay đổi schema.

Baseline database chưa được thêm vì chủ dự án sẽ chủ động đưa tài liệu/schema đã chọn vào repository.
