# Requirements

Thư mục này chứa bản tóm tắt có ID và ma trận truy vết phục vụ phát triển. Tài liệu nguồn do chủ dự án đưa vào `reference/requirements/` và đăng ký trong `reference/SOURCE_REGISTER.md`.

Khi có mâu thuẫn:

1. Ghi nhận sự khác biệt trong task hoặc `DECISIONS_PENDING.md`.
2. Không tự sửa yêu cầu để khớp code hiện tại.
3. Xin phê duyệt quyết định.
4. Cập nhật requirement index, ADR, module docs và test sau khi được chốt.
