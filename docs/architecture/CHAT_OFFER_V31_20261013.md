## Ranh giới và state

Communication sở hữu thread/message/offer/block/media và agreement checkout contract. Identity kiểm customer/role/governance và khóa hai user theo thứ tự ID. Catalog adapter đọc context/snapshot và khóa product; Commerce adapter đọc nghĩa vụ/phí; TrustSafety giữ bằng chứng; Platform sở hữu audit/outbox. Adapters đọc dữ liệu của module mình đặt trong infrastructure. Không gọi repository của module khác từ application service mới.

Command locks theo UUID → user pair → product → conversation → offer. Send/media dùng user pair/conversation; checkout offer giữ cùng thứ tự. Mã gửi và command payload cho phép retry, phát hiện conflict; cursor đơn điệu; unique pending và accepted_offer_id giữ một lần sử dụng. Offer creation/counter/decision/notice cùng transaction. Checkout bind fingerprint/item/reservation/link/notice cùng transaction; replay trả đơn cũ, hủy/refund không tái dùng offer.

Permission projection của detail bắt denial để trả canSend/canOffer/canCheckout. Các guard đọc Identity không đánh dấu transaction rollback chỉ vì permission denial đã được xử lý; command ngoài vẫn rollback khi exception đi ra. PostgreSQL tests xác minh restricted history không phát UnexpectedRollbackException.

Forward-fix bằng migration mới. Khi cần phục hồi: dừng đúng backend, restore backup đã kiểm vào database phục hồi rồi đổi cấu hình và dùng artefact phù hợp; không xóa audit/ledger hoặc sửa checksum V31 để downgrade.
