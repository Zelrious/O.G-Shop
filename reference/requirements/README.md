# Requirement references

Đặt bản phân tích yêu cầu, tổng quan đề tài và tài liệu tham khảo tại đây; sau đó cập nhật `../SOURCE_REGISTER.md` với đúng trạng thái nguồn.

Các file trong thư mục này không mặc nhiên là requirement cuối cùng. Requirement đang áp dụng được duy trì tại `docs/requirements/`, có thể cập nhật theo quyết định mới của chủ dự án và phải được đối chiếu với module, database, API, giao diện cùng kiểm thử liên quan.
