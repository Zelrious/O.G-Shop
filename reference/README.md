# Reference sources

Đây là vùng nhận tài liệu đầu vào do chủ dự án chủ động lựa chọn và sao chép vào repository.

1. Đặt file vào nhóm phù hợp.
2. Đăng ký file trong `SOURCE_REGISTER.md` với nguồn, ngày, trạng thái duyệt và phạm vi sử dụng.
3. Không coi tài liệu chưa duyệt là yêu cầu chính thức.

Scaffold không tự động sao chép file từ thư mục Downloads, thư mục Database cũ hoặc bất kỳ vị trí nào khác.
