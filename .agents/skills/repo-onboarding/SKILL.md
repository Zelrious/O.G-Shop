# Repository onboarding

1. Follow `../../workflows/session-start.md`.
2. Read root `AGENTS.md`, `docs/progress/STATUS.md`, `docs/modules/INDEX.md` and the active task.
3. Inspect `git status`, relevant code/tests and only the module docs needed for the request.
4. Report verified state, open decisions and the approval-gated next action.

Do not infer progress from filenames or earlier chat; verify it from repository state.
