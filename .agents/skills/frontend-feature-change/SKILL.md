# Frontend feature change

1. Read `../../rules/frontend.md`, security/testing rules and the owning module document.
2. For screen design, page layout, design tokens, responsive UI, or reusable visual components, also follow `../marketplace-ui-implementation/SKILL.md`.
3. Define route/page/feature/shared ownership and all loading, empty, error, unauthorized and success states.
4. Apply the approval report before editing.
5. Keep business interaction in the feature and reusable domain-neutral parts in `shared`.
6. Run lint, typecheck, tests and build; record evidence and update docs.
