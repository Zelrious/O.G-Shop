# Frontend feature change

1. Read `../../rules/frontend.md`, security/testing rules and the owning module document.
2. Define route/page/feature/shared ownership and all loading, empty, error, unauthorized and success states.
3. Apply the approval report before editing.
4. Keep business interaction in the feature and reusable domain-neutral parts in `shared`.
5. Run lint, typecheck, tests and build; record evidence and update docs.
