# Session handoff

1. Follow `../../workflows/session-close.md` and `../../rules/documentation-and-handoff.md`.
2. Compare the actual diff and test results with the approved task.
3. Update owning module docs and progress documents from evidence.
4. Archive only completed tasks; keep partial work active with a precise next step.
5. Provide the required before/after explanation and disclose failures or blocked work exactly.
