# Documentation and handoff

Khi bắt đầu task, tạo/cập nhật `docs/progress/active/<task-id>.md` với mục tiêu, phạm vi được duyệt và điều kiện chấp nhận.

Trước khi kết thúc:

1. Cập nhật tài liệu của module bị tác động.
2. Cập nhật requirement/traceability/API/ADR nếu hợp đồng tương ứng đổi.
3. Ghi file thay đổi và bằng chứng kiểm tra trong task.
4. Đồng bộ `STATUS.md`, `BACKLOG.md` và `DECISIONS_PENDING.md`.
5. Chuyển task hoàn tất sang `docs/progress/archive/`.

Tài liệu phải phản ánh trạng thái thật tại commit hiện tại.
