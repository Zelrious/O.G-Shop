# Session start

1. Đọc `AGENTS.md` và `docs/progress/STATUS.md`.
2. Đọc `docs/modules/INDEX.md`, task đang active và module docs liên quan.
3. Kiểm tra `git status`, diff, code và test hiện có.
4. Chọn đúng rules/workflow/skill cần dùng.
5. Xác định fact, giả định, câu hỏi và phạm vi.
6. Lập báo cáo trước thay đổi theo approval gate; chỉ triển khai sau phê duyệt.
