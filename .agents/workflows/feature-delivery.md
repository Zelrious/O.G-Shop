# Feature delivery

1. Chạy workflow bắt đầu phiên và phân tích tác động yêu cầu.
2. Viết task với điều kiện chấp nhận và phạm vi được duyệt.
3. Thiết kế hợp đồng từ ngoài vào: UI/API/application/domain/persistence.
4. Triển khai lát dọc nhỏ nhất; giữ boundary và secure defaults.
5. Test đường chính, lỗi và authorization/concurrency liên quan.
6. Chạy quality gate Backend/Frontend cần thiết.
7. Đồng bộ module docs, traceability, API và tiến trình.
8. Báo cáo sau thay đổi với bằng chứng trước/sau.
