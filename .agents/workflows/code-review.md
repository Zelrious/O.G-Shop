# Code review

1. Đọc mục tiêu task, yêu cầu và module boundary.
2. Review correctness, authorization, transaction/concurrency, data integrity và compatibility trước style.
3. Kiểm tra test có chứng minh rủi ro thật và tài liệu có khớp code.
4. Mỗi phát hiện nêu mức độ, trigger, hậu quả, file/dòng và hướng sửa.
5. Không khẳng định lỗi nếu thiếu đường tái hiện hoặc bằng chứng từ code.
