# Requirement impact analysis

1. Xác định nguồn đã đăng ký và trạng thái duyệt.
2. Chuẩn hóa actor, trigger, precondition, main flow, alternate/error flow, postcondition và rule.
3. Gắn requirement/use-case ID; tìm requirement liên quan hoặc mâu thuẫn.
4. Ánh xạ module, API, bảng, UI, security, test và tài liệu bị tác động.
5. Tách MVP, deferred, mô phỏng/sandbox và câu hỏi cần chốt.
6. Cập nhật traceability sau khi phương án được duyệt.
