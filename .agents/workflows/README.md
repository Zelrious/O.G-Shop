# Agent workflows

| Workflow | Khi dùng |
|---|---|
| `session-start.md` | Bắt đầu mọi phiên làm việc |
| `requirement-impact-analysis.md` | Phân tích yêu cầu hoặc phạm vi |
| `feature-delivery.md` | Thêm chức năng |
| `bug-fix.md` | Sửa lỗi có thể tái hiện |
| `database-change.md` | Thay đổi schema/query/seed |
| `api-contract-change.md` | Thay đổi request/response/status |
| `security-review.md` | Review bề mặt tấn công và quyền |
| `documentation-sync.md` | Đồng bộ tài liệu sau thay đổi |
| `code-review.md` | Review thay đổi trước merge |
| `session-close.md` | Kết thúc và bàn giao phiên |
